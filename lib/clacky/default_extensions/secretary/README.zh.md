# 生活秘书

一个可以「交给它去做」的助理会话：简单问题当场回答，耗时的事派到后台执行，有结果或需要你拍板时再回来找你。

> 本扩展**默认启用**。新建会话时选择「生活秘书」，右侧面板会出现 **「工作事项」** 标签页。

## 适合交给它的事

- 需要查资料、读文档、对比方案的调研类工作
- 需要写文件、改代码、整理数据的执行类工作
- 需要等外部回复的事（例如发出消息后等对方答复）
- 每天早上/每天固定时间的例行汇总

## 怎么用

直接说出目标、可接受的完成标准和已知限制即可，例如：

> 帮我把这个项目的 README 补齐，重点写部署和本地开发两部分，不要改代码。

秘书会判断这件事是否需要后台执行：

- **简单问题**：直接回答，不占用「工作事项」。
- **耗时的工作**：拆成一项「工作事项」，派给后台的工作助手，然后立刻回到和你的对话，不让你等。

## 「工作事项」面板

每个事项一张卡片，显示标题、状态和创建时间，按创建顺序排列，状态变化不会打乱位置。

状态含义：

| 状态 | 含义 |
| --- | --- |
| 等待开始处理 | 已排入队列，尚未开始 |
| 秘书正在处理 | 后台正在执行 |
| 等待外部事件或定时检查 | 等对方回复，或等到指定时间再检查 |
| 等待秘书协助 | 需要信息、决定或授权，秘书会来问你 |
| 已暂停 | 你或秘书暂停了这件事 |
| 已完成 | 有交付物或阶段结果 |
| 遇到问题 | 执行失败，需要和秘书一起处理 |
| 已取消 | 已终止，不会继续 |

卡片上可以：

- **与秘书讨论**：把「关于「标题」，我想补充：」预填到输入框，接着聊就行。
- **查看执行记录**：跳到后台工作助手的会话，看完整的执行过程。
- **事项详情**：展开目标、约束和历次变更记录。

面板底部还有 **「定时安排」** 区，列出每天/工作日固定时间执行的计划、下次执行时间和计划内容。想调整时点「与秘书讨论」，用一句话说明改法即可。

## 后台执行是怎么进行的

1. 秘书把目标、背景、授权边界和验收标准写成任务，交给后台工作助手。
2. 工作助手在**自己的会话**里使用现有工具执行，并遵守你当前的权限与确认设置。
3. 执行告一段落时它会回报结果，可能是：完成、需要你决定、或需要等外部事件。
4. 秘书收到回报后告诉你结论；需要你拍板时，它会先问，再把你的答复转达回去。

同一件事可以在原会话里继续追加要求，不需要重新开一项。

## 注意事项

- 后台执行不阻塞对话，你可以随时插话、改需求或让它取消。
- 工作助手不会自行扩大授权：遇到需要新权限或超出范围的步骤，它会先回来问。
- 显示「已完成」只代表这一轮工作交付了结果，是否接受由你决定，可以继续提修改意见。
- 定时安排依赖本机运行的服务，机器关机或服务停止时不会执行。

## 扩展信息

- 扩展 ID：`secretary`
- 提供内容：对话代理「生活秘书」、后台代理「秘书工作助手」、工具 `delegate_work` / `manage_work` / `yield_work`、面板「工作事项」、接口 `/api/ext/secretary/work`
