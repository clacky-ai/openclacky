# 工作建议

每轮任务结束后，AI 会回顾刚完成的工作，在输入框上方给出 **3 条下一步建议**，让你不用想"接下来该做什么"。

## 怎么用

1. 正常和 AI 对话、让它干活。
2. 一轮任务完成后，输入框上方会出现「接下来建议」卡片（生成时显示「正在生成建议…」）。
3. 对任意一条建议：
   - **点击建议文字**：内容会填进输入框，你可以先修改再发送。
   - **点击「直接发送」**：原样发给 AI，立即执行。
4. 不需要时点卡片右上角 **✕（收起本次）**，下一轮会重新出现。

建议通常覆盖三个不同方向：继续 / 修复、验证、收尾。不会自动执行任何操作，一切由你决定。

## 开关

- 卡片上的 **⏻** 按钮可一键关闭工作建议。
- 关闭后可在「设置 → 工作建议」中重新开启。
- 也可以在扩展管理里整体停用本扩展。

## 小贴士

- 建议只基于本轮实际发生的事情生成，不会编造文件或命令。
- 如果没有合理的下一步，卡片不会出现。
