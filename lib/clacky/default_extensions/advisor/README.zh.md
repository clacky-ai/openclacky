## 入口

- **输入框上方**：每轮任务结束后自动出现「接下来建议」卡片，3 条下一步建议。
- **设置 › 工作建议**：卡片上的 ⏻ 可一键关闭，关闭后在这里重新打开。
- 状态：默认启用。

## 怎么用

1. 正常和 AI 对话、让它干活。
2. 一轮任务完成后，输入框上方出现建议卡片（生成时显示「正在生成建议…」）。
3. 对任意一条建议：
   - **点建议文字**：内容填进输入框，可以先改再发。
   - **点「直接发送」**：原样发给 AI，立即执行。
4. 不需要时点卡片右上角 **✕（收起本次）**，下一轮会重新出现。

建议通常覆盖三个不同方向：继续或修复、验证、收尾。不会自动执行任何操作，一切由你决定。

## 注意事项

- 建议只基于本轮实际发生的事情生成，不会编造文件或命令。
- 没有合理的下一步时，卡片不会出现。
- 也可以在扩展管理里整体停用本扩展。
