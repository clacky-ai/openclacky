## 入口

- **左侧栏底部「知识库」**（在「创作者中心」下方）：打开管理界面，整理和导入资料。
- **会话选择「知识库」agent**：只根据你的资料回答问题。
- 状态：默认关闭。先在 **扩展 › 全部 › 官方** 里启用「知识库」，左侧栏入口和 agent 卡片才会出现。停用后入口、工具和自动检索一起消失，已导入的资料不受影响。

## 怎么用

### 管理资料

打开左侧栏「知识库」，是一个整页管理界面：

- **按目录管理**：左侧是目录列表（一本书、一个项目各一个目录），点「+」新建，鼠标移上去可重命名、删除。右侧是选中目录里的内容，以卡片列表展示，层级不限（书 → 章 → 节），顶部面包屑可回到任一上层。
- **搜索与排序**：搜索框在当前位置及其子文件夹内按标题、来源搜索；旁边菜单可按名称（默认）或更新时间排序。
- **编辑**：点某篇资料打开 Markdown 编辑器，左边编辑、右边实时预览，保存后立即生效。没有放进任何目录的资料会归到「未归档」。
- **整理**：鼠标移到资料上可「重命名」「移到…」（可移到任一目录的任一层）、删除；子文件夹可重命名、删除（连同其中资料一起移到回收站）。文件夹只用于管理，AI 检索始终覆盖整个知识库，回答时出处会带上所在文件夹（如「青岚茶志 / 第一章」）。

### 添加数据源

- **上传文件**：存到当前打开的位置（需先选中一个目录）。一次一份 md、txt、PDF 或 Word（doc / docx / wps）。先转成文字，在编辑器里预览，可直接修改，点「导入」才入库，取消则不保存。
- **导入文件夹**：用系统的文件夹选择窗口选一个文件夹（选的是你自己电脑上的文件夹，云端部署也一样）。浏览器会先确认「上传 N 个文件」，随后弹出待导入清单（相对路径），可取消勾选不需要的，点「导入」后逐个上传入库，不逐份预览内容。所选文件夹会整个放进当前文件夹，原有子文件夹层级完整保留，导入多本书时每本书各是一个文件夹。导入后与原文件夹无关。
- PDF、Word 的文字是自动识别的，扫描件和复杂排版可能有错，入库后也可以随时点开修改。
- **删除**：资料和文件夹都移到回收站，可以恢复，不会直接抹掉。删光资料后文件夹本身保留。

### 召回测试

在管理界面按用户的问法输入问题，查看知识库 agent 会检索到哪些段落，排在前几位的标为「会使用」。适合用来检查资料是否覆盖、问法能否命中。搜索框会记住最近查过的问题，点右侧时钟图标可以直接重跑，也可以一键清空。

### 提问

会话里把 agent 切到「知识库」，直接提问即可。它的工作方式：

- **每次提问前自动检索**：把最相关的片段连同标题和出处一起交给 AI，再由它作答。
- **需要时可以再查**：换个关键词重新检索，或者逐篇翻看资料、只在这一篇里找关键字。
- **回答规则**：先查知识库，需要说明出处时直接写资料名；资料里没有就直说没找到，不用自己的常识补齐，也不编造。

### 资料的标题和出处

上传 md / txt 文件时，可以在正文前加一小段说明，自定义标题和出处；不写就用文件名当标题，出处也用文件名：

```markdown
---
title: 振成楼门楼
source: 《振成楼志》第 12 页
---

正文……
```

### 生效范围

在 **设置 › 通用 › 默认 Agent** 里选「知识库」，以下会话都会用它：

- 新建会话
- 侧栏的快捷新建
- 渠道会话（飞书、微信等）

默认 Agent 改回「日常工作」后，知识库只在你手动选择「知识库」卡片的会话里生效。

### 检索方式

检索在本机完成，不需要联网，也不需要额外配置向量模型。

## 注意事项

- 知识库 agent 只能检索你的资料：不能执行命令、读写文件、上网搜索、操作浏览器、使用技能，也不读写长期记忆。与知识库无关的请求只回一句「这个问题和知识库无关，我无法回答。」，不给替代方案、不列命令、不做其他建议（打招呼或问「你是谁」时允许先简短自我介绍一次）。需要完整能力时，切回「日常工作」agent。
- 其他 agent（日常工作、编程开发等）不注入知识库，也没有上面两个工具；子 agent 同样不注入。
- 定时任务固定使用「日常工作」agent，不受默认 Agent 影响。
