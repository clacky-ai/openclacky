# 知识库（knowledge）

这个扩展提供一个「知识库」agent，只做一件事：根据你的资料回答问题。适合给导游、学生、渠道用户这类不该碰你电脑的人用。它的工作方式：

- **每次提问前自动检索**：把最相关的片段连同标题和出处注入给 AI，再由 AI 作答。
- **能主动补充查询**：AI 可以调用两个工具，
  - `kb_search`：换个关键词再检索
  - `kb_read`：按 id 读整篇；传 `pattern` 时只在这一篇里 grep
- **回答规则**：先查知识库，需要说明出处时直接写资料名；资料里没有就直说没找到，不用自己的常识补齐，也不编造。
- **只答知识库**：只有 `kb_search`、`kb_read` 两个工具，不能执行命令、读写文件、上网搜索、操作浏览器、使用技能，也不读写长期记忆。与知识库无关的请求只回一句「这个问题和知识库无关，我无法回答。请提问知识库里的内容。」，不给替代方案、不列命令、不做其他建议（打招呼或问「你是谁」时允许先简短自我介绍一次）。需要完整能力时，切回「日常工作」agent。

其他 agent（日常工作、编程开发等）不注入知识库，也没有上面两个工具；子 agent 同样不注入。

## 启用

这个扩展**默认不开启**。在 **扩展 › 全部 › 官方** 里点「知识库」右侧的 `+` 启用，新建会话页就会出现「知识库」卡片。停用后卡片、工具和自动检索都会一起消失，`~/.clacky/knowledge/` 里的资料不受影响。

## 生效范围

启用后，在 **设置 › 通用 › 默认 Agent** 里选「知识库」，以下会话都会用它：

- 新建会话
- 侧栏的快捷新建
- 渠道会话（飞书、微信等）

定时任务固定使用「日常工作」agent，不受影响。

默认 Agent 改回「日常工作」后，知识库只在你手动选择「知识库」卡片的会话里生效。

## 怎么开始

**把 md 文件放进 `~/.clacky/knowledge/entries/` 就生效**，不需要任何配置。这个目录在服务启动时会自动建好；子目录随意，比如按点位、人物分。

```
~/.clacky/knowledge/
└── entries/
    ├── 点位/
    │   └── 振成楼-门楼.md
    └── 人物/
        └── 林鸿超.md
```

可用环境变量 `CLACKY_KNOWLEDGE_DIR` 改目录。

## kb.yml（可选）

只有想关掉知识库或调整参数时才需要建 `~/.clacky/knowledge/kb.yml`：

```yaml
enabled: false        # 写 false 关闭；不写或没有这个文件 = 开启
inject_top_k: 5       # 每次注入几条，默认 5
version: 1            # 内容包版本，导出导入时用
```

管理页暂不提供这些设置，需要时手动编辑此文件。

## 条目格式

每个条目是一个 md 文件，开头可写 frontmatter（都可省略）：

```markdown
---
id: zcl-menlou            # 省略时用 entries/ 下的相对路径
title: 振成楼门楼          # 省略时用文件名
source: 《振成楼志》第 12 页
---

正文……
```

## 入库

启用后，侧栏「创作者中心」下方会出现 **知识库** 入口，打开后是一个整页管理界面：

- **按目录管理**：左侧是目录列表（如一本书、一个项目各一个目录），点「+」新建，鼠标移上去可重命名、删除。右侧是选中目录里的内容，以卡片列表展示，可「新建目录」，层级不限（如 书 → 章 → 节），顶部面包屑可回到任一上层。搜索框在当前位置及其子文件夹内按标题、来源搜索。旁边的排序菜单可按名称（默认）或更新时间排列。点某篇资料会打开 Markdown 编辑器，左边编辑、右边实时预览，保存后立即生效。每篇资料都放在某个目录里；直接放在 `entries/` 最外层的文件会归到左侧的「未归档」。
- **整理**：鼠标移到资料上，可「重命名」「移到…」（可移到任一目录的任一层）、删除；子文件夹可重命名、删除（连同其中资料一起移到回收站）。文件夹只用于管理，AI 检索始终覆盖整个知识库，回答时出处会带上所在文件夹（如「青岚茶志 / 第一章」）。
- **添加数据源**：
  - **上传文件**：存到当前打开的位置（需先选中一个目录）。一次一份 md、txt、PDF 或 Word（doc / docx / wps）。先转成文字，在编辑器里预览，可直接修改，点「导入」才入库，取消则不保存。
  - **导入文件夹**：用系统的文件夹选择窗口选一个文件夹（选的是你自己电脑上的文件夹，云端部署也一样）。浏览器会先确认「上传 N 个文件」，随后弹出待导入清单（相对路径），可取消勾选不需要的，点「导入」后逐个上传入库，不逐份预览内容。所选文件夹会整个放进当前文件夹，原有子文件夹层级完整保留，导入多本书时每本书各是一个文件夹。导入后与原文件夹无关。
  - PDF、Word 的文字是自动识别的，扫描件和复杂排版可能有错，入库后也可以随时点开修改。
- **删除**：资料和文件夹都移到回收站，可以恢复，不会直接抹掉。删光资料后文件夹本身保留。
- **召回测试**：按用户的问法输入问题，查看知识库 agent 会检索到哪些段落，排在前 `top_k` 的标为「会使用」。适合用来检查资料是否覆盖、问法能否命中。搜索框会记住最近查过的问题，点输入框右侧的时钟图标可以直接重跑，也可以一键清空。

也可以继续直接把 md 文件放进 `entries/`，两种方式等价。改动会在下一次提问时自动生效（按文件修改时间重建索引）。

## 检索方式

内存 BM25：中文按相邻两字切词，英文数字按单词；正文按段落切成约 600 字的片段，每个条目取最相关的一段。不依赖向量模型，也不需要联网。
