# 预览

内置的迷你浏览器：AI 做出来的网页、本地启动的开发服务，不用切换窗口，直接在会话右侧查看和操作。

## 怎么打开

- **最简单**：在聊天里点击 AI 给出的 HTML 文件或 `localhost` 链接，预览面板会自动打开并加载。
- **手动**：在会话右侧面板切换到 **「预览」** 标签页，在地址栏输入地址后回车。

地址栏支持：

- 工作区里的文件路径，例如 `index.html`、`dist/report.html`
- 本地开发服务，例如 `localhost:3000`、`http://127.0.0.1:5173`
- 普通网址，例如 `https://example.com`

## 工具栏

| 按钮 | 作用 |
|---|---|
| ← / → | 后退 / 前进 |
| ⟳ | 刷新页面（AI 改完代码后点一下就能看到最新效果） |
| ↗ | 在浏览器新标签页中打开 |
| 更多 | 缩放：放大 / 缩小 / 重置为 100% |

## 小贴士

- 页面在独立的安全环境中运行，无法读取 Clacky 自身的数据；本地 Rails、React、Vue 等应用的点击、表单、登录都能正常使用。
- 文件不存在或服务没启动时，会显示友好的提示页，而不是一片空白。请确认路径正确或开发服务已启动。
- 在页面里点链接跳转后，地址栏会自动同步到当前地址。
