## 入口

- 通用助手会话右侧面板 → **「会议助理」** 标签页。
- 状态：默认关闭。先在 **扩展 › 全部 › 官方** 里启用「会议助理」。

## 使用前准备

- 配置一个可用的模型服务：语音识别和纪要生成都用它。
- 告知与会者会议正在录音并转写。

## 怎么用

### 开始一场会议

1. 打开通用助手会话，在右侧面板切换到「会议助理」。
2. 点击 **「开始记录」**，按浏览器提示允许使用麦克风。
3. 发言内容会实时转成字幕显示在面板里。
4. 会议过程中，AI 每隔约 2 分钟会自动整理一次「标注」（要点摘录）。

### 会中向 AI 提问

说出唤醒词，后面接你的问题即可，例如「你好小克，刚才说的上线时间是哪天？」

支持的唤醒词：

- 「你好小克」「小克小克」
- 「你好克拉奇」
- 「hey clacky」「@clacky」

AI 会用语音回答。可以随时点击：

- **停止播报**：停止当前语音播放
- **打断**：取消当前回答

### 结束会议

点击 **「总结记录」**，AI 会根据完整转写内容生成结构化纪要，包含：

- 关键决策
- 待办事项（能识别时附上负责人）
- 讨论要点
- 未决问题

不想生成纪要时点 **「取消」**：会丢弃这次录音，不调用 AI。

### 静音与续录

- **静音 / 解除静音**：临时关闭麦克风，不记录这段时间的发言。
- **继续录音**：刷新页面或中断后，可以接着之前的会议继续记录（需要重新授权麦克风）。
- **会议词汇**：在「会议词汇（专有名词）」中输入人名、产品名、术语，回车添加后点「保存词汇」，能明显提高识别准确率。

## 注意事项

- 会议录音和转写涉及他人发言，使用前请告知与会者。
