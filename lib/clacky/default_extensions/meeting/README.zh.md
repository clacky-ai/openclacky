# 会议助理

开会时让 AI 旁听：实时显示字幕，随时语音提问，会议结束后自动生成会议纪要。

> 本扩展**默认关闭**。在扩展管理中点击「启用」后，会在通用助手会话的右侧面板出现 **「会议助理」** 标签页。

## 开始一场会议

1. 打开通用助手会话，在右侧面板切换到「会议助理」。
2. 点击 **「开始记录」**，按浏览器提示允许使用麦克风。
3. 发言内容会实时转成字幕显示在面板里。
4. 会议过程中，AI 每隔约 2 分钟会自动整理一次「标注」（要点摘录）。

## 会中向 AI 提问

说出唤醒词，后面接你的问题即可，例如「你好小克，刚才说的上线时间是哪天？」

支持的唤醒词：

- 「你好小克」「小克小克」
- 「你好克拉奇」
- 「hey clacky」「@clacky」

AI 会用语音回答。可以随时点击：

- **停止播报**：停止当前语音播放
- **打断**：取消当前回答

## 结束会议

点击 **「总结纪要」**，AI 会根据完整转写内容生成结构化纪要，包含：

- 关键决策
- 待办事项（能识别时附上负责人）
- 讨论要点
- 未决问题

## 其他功能

- **静音 / 解除静音**：临时关闭麦克风，不记录这段时间的发言。
- **继续录音**：刷新页面或中断后，可以接着之前的会议继续记录（需要重新授权麦克风）。
- **会议词汇**：在「会议词汇（专有名词）」中输入人名、产品名、术语，回车添加后点「保存词汇」，能明显提高识别准确率。

## 注意事项

- 语音识别使用当前配置的模型服务，请确保已配置可用的模型。
- 会议录音和转写涉及他人发言，使用前请告知与会者。
