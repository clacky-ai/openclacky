## 入口

- 会话右侧面板的标签栏 → 点 **＋（新标签页）** → **官方 › 终端**。
- 状态：默认关闭。先在 **扩展 › 全部 › 官方** 里启用「终端」。
- 前提：界面是从本机打开的；通过局域网/远程地址访问时用不了。

## 怎么用

### 打开与关闭

- 一个会话一个 shell，起始目录就是这个会话的工作目录（AI 干活的目录）；没有会话目录时用用户主目录。
- 切到别的标签页或别的会话，shell 继续在后台跑；切回来时，期间打印的内容会补上。
- 用 × 关掉标签页不会杀掉进程；再添加「终端」就接回同一个 shell。
- 输入 `exit`（或 `Ctrl+D`）退出后，这个标签页会自动关掉；再添加「终端」得到一个新 shell。

### 常用操作

| 想做什么 | 怎么做 |
|---|---|
| 跑命令 / 装依赖 | 直接输入，跟本机终端一样 |
| 停止正在跑的命令 | `Ctrl+C` |
| 挂到后台 | `Ctrl+Z` |
| 清屏 | `clear` 或 `Ctrl+L` |
| 换目录 | `cd`。会话的工作目录（AI 用的那个）不会跟着变 |

## 注意事项

- 终端等于在跑 Clacky 的那台机器上执行命令，所以默认关闭，并且只接受本机请求。
- 跨会话最多同时 6 个 shell；到上限时会回收最久没用、且当前没被页面连着的那个。
- 关掉标签页后如果超过 1 小时没有页面连着它，下次打开终端时会被回收，再打开就是新的 shell。
- shell 活在 Clacky 进程里：重启 Clacky 后它们都没了，标签页会自动关掉，而不是留下一个死掉的窗格。
- Windows 暂不支持，面板会提示无法启动终端。
