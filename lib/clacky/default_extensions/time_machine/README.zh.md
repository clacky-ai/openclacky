# 时光机

AI 每完成一步任务，都会自动给工作区存一个档。改坏了？随时回到之前任意一步。

## 怎么打开

在会话右侧面板切换到 **「时光机」** 标签页，会看到一条按时间排列的任务时间轴。

- 标有 **「当前」** 的是工作区现在所处的版本。
- 每一步显示改动了几个文件以及完成时间。

## 查看某一步改了什么

1. 点击时间轴上的某一步，展开卡片，可以看到主要改动的文件。
2. 点击 **「查看详情」**，进入双栏视图：左边是文件列表，右边是逐行差异。
3. 文件旁的标签说明改动类型：**新增 / 新建 / 修改 / 删除**。
4. 点击 **「返回」** 回到时间轴。

## 回到之前的某一步

1. 展开目标步骤，点击 **「回到这里」**。
2. 面板会先列出将受影响的文件，供你确认。
3. 点击 **「确认回到这里」**，工作区文件会恢复到那一步完成时的状态。

> ⚠️ 回到某一步会覆盖当前工作区中对应文件的修改，请先确认列出的文件。

回到过去的某一步后继续让 AI 工作，会从那里长出新的 **「分支」**，原来的记录不会丢失，之后仍可以切换回去。

## 小贴士

- 存档是自动的，不需要手动保存，也不依赖 Git。
- 想以 Git 的视角审阅改动、按提交或分支对比，可以使用「Git 管理」扩展。
