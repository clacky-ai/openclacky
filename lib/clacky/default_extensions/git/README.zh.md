# Git 管理

一个直观的改动审阅面板：AI 改了哪些文件、改了哪几行，一眼看清，像审阅代码一样逐个确认。

> 需要当前会话的工作目录是一个 Git 仓库。

## 怎么打开

在会话右侧面板中切换到 **「Git 管理」** 标签页。

## 选择查看范围

点击顶部的范围下拉框，可以切换要看的改动：

| 范围 | 说明 |
|---|---|
| 上一轮 | 只看 AI 上一轮任务改了什么（最常用） |
| 未提交 | 自上次提交以来的全部改动 |
| 未暂存 / 已暂存 | 按 Git 暂存区拆分查看 |
| 已提交 | 当前分支相对基线分支的提交 |
| 未推送的提交 | 还没 push 到远端的提交，可逐个查看 |
| 分支 | 选择任意分支进行对比 |

## 浏览改动

- **左侧文件树**：列出所有改动文件，可拖动调整宽度（双击复位），也可以收起。
- **跳转到文件**：输入文件名快速筛选定位。
- **差异布局**：自动 / 并排 / 行内，点击切换。
- **自动换行**：长行太多时打开。
- 未修改的代码会折叠成「N 行未修改」，点击展开。
- 改动很大的文件会延迟加载，点一下再显示。

## 对文件进行操作

- **撤销此文件的改动**：点文件头部的撤销按钮，再次确认后丢弃该文件的改动（不可恢复，请谨慎）。
- **更多菜单 / 右键**：复制路径、复制相对路径、在编辑器中打开、添加到聊天、打开所在文件夹、下载。

## 小贴士

- 想让 AI 针对某个文件继续修改？用「添加到聊天」把它带进输入框。
- 只想回看 AI 某一步的改动，或整体回退，可配合「时光机」扩展使用。
