# 电脑操作

让 AI 像人一样操作你的电脑桌面：截屏看界面，再用鼠标点击、键盘输入。适合处理终端和浏览器够不到的事情。

> 本扩展**默认关闭**。在扩展管理中点击「启用」后生效。

## 适合做什么

- 操作原生应用、系统设置、安装程序
- 处理弹窗、菜单栏、文件选择器
- 其他只能"用手点"的桌面操作

网页上的自动化任务建议优先使用内置的浏览器能力，更快也更稳定；只有浏览器搞不定时再用电脑操作。

## 使用前准备

**macOS**

在「系统设置 → 隐私与安全性」中，为运行 Clacky 的程序（如终端或 Clacky 应用）授予：

- **屏幕录制**（用于截屏）
- **辅助功能**（用于控制鼠标和键盘）

授权后可能需要重启该程序。

**Windows**

需要在 **WSL** 中运行 Clacky，并且是在已登录的桌面会话里（不能是后台服务或 SSH 远程会话），否则截屏会是黑屏、点击无效。

> 纯 Linux 系统暂不支持。

## 怎么用

启用后直接用自然语言描述任务即可，例如：

- 「打开系统设置，把显示器亮度调到最高」
- 「在弹出的文件选择框里选中桌面上的 report.pdf」

AI 会先截屏查看当前屏幕，再按坐标点击、输入，每一步之后重新截屏确认结果。

## 遇到问题

对 AI 说「运行 computer-use 的 doctor 自检」，它会检查权限和环境，并告诉你缺什么。

## 注意事项

- AI 操作期间请尽量不要动鼠标键盘，以免互相干扰。
- 涉及付款、删除等敏感操作时，请留意 AI 的每一步。
